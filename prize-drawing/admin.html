Instructions

How to Use

  1. Add prizes in the Prizes tab
  2. Set probability percentages (should total 100%)
  3. Add milestone prizes in the Milestones tab (optional)
  4. Open index.html to run the prize drawing

Probability System

  • Total probability should equal 100%
  • If total is less than 100%, remaining % is unused
  • If total exceeds 100%, probabilities are normalized

Milestone Prizes

  • Awarded at specific spin numbers
  • Override normal probability drawing
  • Each milestone can only be awarded once

Keyboard Shortcuts

  • Space or Enter - Spin the wheel
  • Space or Enter - Close result popup
