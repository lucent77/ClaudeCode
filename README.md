# Swissturn 생산 관리 시스템

Swissturn 부서를 위한 통합 생산 및 공구 관리 웹 시스템입니다. PHP와 Tailwind CSS로 개발되었으며, Hostinger에서 호스팅할 수 있도록 설계되었습니다.

## 주요 기능

### 1. 통합 대시보드
- 실시간 장비 현황 모니터링 (8대 CNC 장비: MP1~MP3, HW1~HW5)
- 공구 수명 추적 및 교체 필요 알림
- 생산 실적 및 장비 가동률(OEE) 시각화
- 주간/월간 생산 통계

### 2. 장비 관리
- 8대 CNC 장비 상태 관리 (가동중/대기/정비/오류)
- 장비별 총 가동시간 추적
- 장착된 공구 현황
- 생산 기록 연동

### 3. 공구 관리
- 공구 목록 및 상세 정보 관리
- 공구 수명 추적 (사용시간/수명 비율)
- 공구 상태 관리 (신규/사용중/사용완료/정비/폐기)
- 공구 재고 관리
- CSV 일괄 업로드

### 4. 장비별 공구 세팅
- 각 장비에 장착된 공구 관리
- 공구 추가/제거 기능
- 공구 사용 비율 설정
- 공구 교체 이력 추적

### 5. 생산 기록
- 일일 생산 실적 입력 및 조회
- 장비별 가동시간 기록
- 달성률 자동 계산
- CSV 일괄 업로드
- 공구 사용시간 자동 누적

### 6. 공구 사용 시간 추적
- 생산 기록 입력 시 장착된 공구의 사용시간 자동 누적
- 공구별 사용 비율에 따른 정확한 시간 계산
- 공구 수명 소진율 실시간 계산
- 80% 이상 사용 시 경고 표시

### 7. 사용자 역할
- **관리자 (Admin)**: 모든 기능 접근, 데이터 업로드, 설정 변경
- **작업자 (Operator)**: 데이터 조회, 제한된 입력 기능

## 시스템 요구사항

- PHP 7.4 이상
- MySQL 5.7 이상
- Apache 웹 서버 (mod_rewrite 활성화)
- 최소 256MB RAM

## Hostinger 설치 가이드

### 1. 파일 업로드

1. Hostinger 파일 매니저 또는 FTP를 통해 모든 파일을 `public_html` 디렉토리에 업로드합니다
2. 다음 디렉토리 구조를 확인합니다:

```
public_html/
├── api/
├── assets/
├── config/
├── includes/
├── uploads/
├── index.php
├── login.php
├── dashboard.php
├── equipment.php
├── tools.php
├── tool_settings.php
├── production.php
├── upload.php
├── database.sql
└── README.md
```

### 2. 데이터베이스 설정

1. Hostinger 관리 패널에서 MySQL 데이터베이스를 생성합니다
   - 데이터베이스 이름: `swissturn_db` (또는 원하는 이름)
   - 사용자를 생성하고 모든 권한을 부여합니다

2. phpMyAdmin에 접속하여 `database.sql` 파일을 임포트합니다
   - phpMyAdmin → Import → Choose File → database.sql 선택 → Go

3. `config/database.php` 파일을 열어 데이터베이스 정보를 수정합니다:

```php
define('DB_HOST', 'localhost');  // 또는 Hostinger에서 제공하는 호스트
define('DB_NAME', 'swissturn_db');  // 생성한 데이터베이스 이름
define('DB_USER', 'your_username');  // 데이터베이스 사용자명
define('DB_PASS', 'your_password');  // 데이터베이스 비밀번호
```

### 3. 디렉토리 권한 설정

uploads 디렉토리에 쓰기 권한을 부여합니다:
- 파일 매니저에서 `uploads` 폴더 우클릭 → Permissions → 755

### 4. 시스템 접속

웹 브라우저에서 도메인에 접속합니다:
- 예: `https://yourdomain.com` 또는 `https://yourdomain.com/index.php`

## 데이터 업로드 가이드

### 공구 데이터 (Tool.csv)

CSV 파일은 다음 컬럼을 포함해야 합니다:

| 컬럼명 | 설명 | 예시 |
|--------|------|------|
| Tool Code | 공구 코드 (필수) | D-08 |
| Tool Name | 공구 이름 (필수) | .80 DRILL |
| Category Name | 카테고리 | TWIST DRILL |
| Tool Size | 크기 | 0.8 |
| Supplier Name | 공급업체 | OSG |
| Supplier Model Number | 모델 번호 | 3300120 |
| Current Stock | 현재 재고 | 5 |
| Minimum Stock | 최소 재고 | 5 |
| Lifespan Type | 수명 타입 | time |
| Lifespan Limit | 수명 한계 (필수) | 200 |
| Description | 설명 | High-speed steel drill |

**업로드 방법**:
1. 관리자 계정으로 로그인
2. 데이터 업로드 메뉴 선택
3. Tool.csv 파일 선택 및 업로드

### 생산 데이터 (Swiss.csv)

CSV 파일은 다음 컬럼을 포함해야 합니다:

| 컬럼명 | 설명 | 예시 |
|--------|------|------|
| DATE | 작업 일자 | 01-03 또는 2025-01-03 |
| MODEL NAME | 모델명 | Z37 Link 6mm |
| SKU | SKU | Z376 |
| LOT NO | LOT 번호 | 241230Z376 |
| WORKER | 작업자 | TJ |

| PLAN | 계획 수량 | 2500 |
| UNIT TOTAL | 실제 생산 수량 | 2300 |
| % | 달성률 | 92 |

**업로드 방법**:
1. 관리자 계정으로 로그인
2. 데이터 업로드 메뉴 선택
3. Swiss.csv 파일 선택 및 업로드

## 주요 기능 설명

### 공구 수명 자동 추적

생산 기록을 입력하면:
1. 해당 장비의 가동시간이 기록됨
2. 장비에 장착된 모든 공구의 사용시간이 자동 누적됨
3. 각 공구의 사용 비율에 따라 정확한 시간 계산
4. 공구 수명 소진율이 실시간으로 업데이트됨

**예시**:
- MP1 장비에 20시간 가동 기록 입력
- 드릴 (사용 비율 50%) → 10시간 누적
- 커터 (사용 비율 30%) → 6시간 누적

### OEE (설비 종합 효율) 계산

OEE는 장비의 가동 상태에 따라 간단히 계산됩니다:
- 가동 중: 85%
- 대기/정비/오류: 0%

향후 실제 생산 데이터를 기반으로 정교한 OEE 계산이 가능합니다.

## 문제 해결

### "Database connection failed" 오류
- `config/database.php`의 데이터베이스 정보가 정확한지 확인
- Hostinger에서 MySQL 서비스가 실행 중인지 확인

### CSV 업로드 실패
- 파일 크기 제한 확인 (Hostinger는 기본 2MB)
- CSV 파일의 인코딩이 UTF-8인지 확인
- 필수 컬럼이 모두 포함되어 있는지 확인

### 페이지가 표시되지 않음
- .htaccess 파일이 올바르게 설정되었는지 확인
- Apache mod_rewrite가 활성화되었는지 확인

### 공구 사용시간이 누적되지 않음
- 생산 기록 입력 시 장비가 올바르게 선택되었는지 확인
- 해당 장비에 공구가 장착되어 있는지 확인
- 공구의 사용 비율이 설정되어 있는지 확인
